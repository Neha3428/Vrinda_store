#  Vrinda Store Data Analysis

##  Project Overview

Vrinda Store Data Analysis is an Excel-based data analysis project focused on understanding sales performance, customer purchasing behavior, product categories, sales channels, and regional trends.

The project involves cleaning and analyzing retail sales data and creating meaningful insights using Microsoft Excel.

##  Objectives

- Analyze overall sales performance
- Understand customer purchasing patterns
- Identify top-performing product categories
- Analyze sales based on gender and age groups
- Identify high-performing states/regions
- Compare different sales channels
- Generate useful business insights from raw data

##  Tools & Technologies

- Microsoft Excel
- Excel Formulas
- Data Cleaning
- Data Analysis
- Charts & Visualizations

##  Analysis Performed

The following areas were analyzed:

-  Customer demographics
-  Gender-wise sales
-  Age-group analysis
-  Category-wise sales
-  Sales channel analysis
-  State-wise sales
-  Overall sales trends
-  Sales performance

##  Data Cleaning

The raw dataset was prepared for analysis by:

- Checking and handling missing values
- Removing duplicate records where required
- Cleaning inconsistent data
- Formatting data properly
- Preparing the dataset for analysis

##  Excel Functions Used

Some of the Excel functions and techniques used in the project include:

- `SUM`
- `AVERAGE`
- `SUMIF`
- `AVERAGEIF`
- Percentage calculations
- Sorting & Filtering
- Conditional Formatting
- Data Visualization

##  Visualizations

Charts and visualizations were created to make the analysis easier to understand and highlight important sales and customer trends.

##  Key Insights

The analysis helps understand:

- Which product categories generate higher sales
- Which customer groups contribute more to sales
- Which states/regions perform better
- How different sales channels contribute to overall sales
- Customer purchasing patterns based on demographics
