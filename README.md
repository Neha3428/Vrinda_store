# Vrinda Store Data Analysis(Excel Dashboard)
## Project Overview

This project analyzes the sales performance of Vrinda Store using Microsoft Excel. The objective is to transform raw sales data into meaningful business insights through data cleaning, analysis, Pivot Tables, Pivot Charts, and an interactive dashboard.
# The analysis helps identify:

Sales trends over time.
Customer demographics.
Order status distribution.
Top-performing states.
Sales channels performance.
Gender and age group purchasing behavior.
Project Objectives

## The main goals of this project are:

Analyze annual sales performance.
Identify top sales channels.
Compare purchasing behavior of men and women.
Find top-performing states based on sales.
Understand customer age-group distribution.
Track order status and fulfillment performance.
Build an interactive Excel dashboard for decision-making.
## Analysis Performed
  Orders vs Sales Analysis,
  Men vs Women Analysis,
  Order Status Analysis,
  Top 5 States by Sales,
  Age & Gender Analysis,
  Sales Channel Analysis.
